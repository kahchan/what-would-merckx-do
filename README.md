# What Would Merckx Do?

A fixed-gear drivetrain calculator for track cyclists and urban fixed riders. Dial in your chainring and cog, compare gear ratios, and see exactly how far each pedal stroke takes you.

**[Try it →](https://kahchan.github.io/what-would-merckx-do/)**
